# Ezidi Calendar Universal V5

نسخة موحدة Responsive مخصصة للهاتف والآيباد والكمبيوتر.

## التصميم
- الكمبيوتر: شريط جانبي + شريط علوي + تقويم شهري واسع + صفحات المناسبات والإعدادات.
- الآيباد: تخطيط متوازن مناسب للشاشة المتوسطة، مع تقويم كامل قابل للنقر.
- الهاتف: واجهة مبسطة + شريط تنقل سفلي + خلايا تقويم مضغوطة.
- نفس الملفات ونفس البيانات لكل الأجهزة.

## المزايا
تقويم شهري، جدول مناسبات، بحث، تفاصيل اليوم/المناسبة، مفضلة، تذكيرات محلية، الوضع الليلي، 4 لغات، مناسبة قادمة، PWA، والعمل دون اتصال بعد أول تحميل.

## إضافة 2027 و2028
ابحث عن `const EVENTS=` داخل index.html وأضف أحداث السنوات الجديدة بنفس الشكل:
["2027-01-02","2027-01-02","EVENT KEY"]
ثم أضف اسم المفتاح في `const N=`.

## بيانات 2026
تم إدخال المناسبات الظاهرة في ملف Ezidische Kalender 2026 كما وردت فيه، بما في ذلك التواريخ الممتدة والتواريخ التاريخية المسجلة في المصدر.
