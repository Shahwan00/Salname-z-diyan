# Ezidi Calendar — النسخة الأولى

تطبيق تقويم إيزيدي متعدد اللغات مبني كـ Progressive Web App (PWA).

## اللغات
- العربية
- English
- Deutsch
- Êzîdî

## ما يحتويه
- تقويم ميلادي شهري.
- المناسبات الإيزيدية لعام 2026 من ملف Ezidische Kalender 2026.
- صفحة للمناسبات.
- البحث في المناسبات.
- صفحة معلومات عن التقويم.
- تغيير اللغة مع حفظ الاختيار.
- الوضع الليلي مع حفظ الاختيار.
- تصميم متجاوب للهاتف والكمبيوتر.
- دعم التثبيت كتطبيق PWA والعمل دون اتصال بعد أول فتح.

## التشغيل
يمكن فتح `index.html` مباشرة للعرض الأساسي.
للاستفادة من PWA وService Worker شغّل المشروع عبر خادم محلي، مثل:

```bash
python -m http.server 8000
```

ثم افتح:
`http://localhost:8000`

## مصدر بيانات 2026
تم إدخال المناسبات والتواريخ من ملف المستخدم:
`Ezidische Kalender 2026.pdf`

ملاحظة: هذه النسخة الأولى لا تدّعي حساب التقويم الإيزيدي للسنوات الأخرى؛ بيانات المناسبات المضمّنة هي بيانات 2026 الواردة في المصدر.
