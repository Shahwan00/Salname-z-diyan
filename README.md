# Ezidi Calendar Universal V4

نسخة واحدة responsive تعمل من نفس الكود على:
- الهاتف Android / iPhone
- iPad والأجهزة اللوحية
- الكمبيوتر واللابتوب
- المتصفحات الحديثة
- ويمكن تثبيتها كتطبيق PWA عندما يدعم المتصفح ذلك.

## المزايا
تقويم 2026، المناسبات، البحث، المفضلة، التذكيرات المحلية، الوضع الليلي، اللغات العربية/English/Deutsch/Êzîdî، عداد للمناسبة القادمة، صفحة إعدادات، وتصميم متجاوب.

## التشغيل
افتح index.html، أو شغّل خادمًا محليًا:
python -m http.server 8000

ثم افتح http://localhost:8000

## ملاحظة
هذه نسخة واحدة من الواجهة وليست أربعة تطبيقات منفصلة. نفس الملفات تتكيف تلقائيًا مع عرض الشاشة.
بيانات المناسبات لعام 2026 مأخوذة من ملف Ezidische Kalender 2026 المرفق بالمشروع.
